The mechanism

Paying an ancestry cannot mean walking one.

The obvious design splits the fee across every ancestor at payment time. It is also the design that dies: gas grows with depth, so the thirtieth generation of a model is unaffordable to query and the lineage stops growing exactly where it gets interesting.

  1. 01

    The fee cleaves once

    A payment landing on a node splits in two — the part it keeps, the part it owes. One arithmetic step, no traversal. O(1), at any depth.

  2. 02

    Settlement walks itself

    Anyone may push a node's debt up exactly one generation. An ancestor wanting its revenue pays the gas to pull value toward itself — O(parents), hard-capped at eight. No one subsidises anyone.

  3. 03

    Nothing is lost in transit

    The last parent absorbs every division remainder, so Σ earned + Σ owed equals the contract balance to the wei. Proven under 256 fuzz runs.

  4. 04

    Cycles are unrepresentable

    Ids increase, and a node may only name parents that already exist. Every edge points backwards in time, so a loop cannot be written — not merely rejected.

What 0G makes possible

The stack this could not have been built without.

0G Storage

Weights, addressed by Merkle root. A fine-tune stores its adapter, not a copy — so thirty generations cost one base model plus thirty deltas. Identical adapters collapse to the same root and the graph dedupes itself.

0G Compute

Fine-tuning, not inference. The direct broker trains against real parent weights on real GPUs and the TEE signs the result — which is what turns "descended from" into a claim that can be checked.

ERC-7857

clone() given an economic meaning: a licensed model is not a copy that escapes its origin, it is a child node. Every inference it ever serves pays the model it came from.

0G Chain

The genealogy itself — nodes, edges, balances, settlement. EVM at a gas price where per-inference royalty accounting is affordable rather than theoretical.
